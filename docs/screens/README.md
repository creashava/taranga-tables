# Taranga Tables — UI Screenshots

This directory holds captured screenshots of every screen at the three standard breakpoints:
- **360×740** — Primary mobile baseline (target for all members)
- **390×844** — iPhone Pro size
- **768×1024** — Tablet / host console

Screenshots were captured at the end of each phase per the BUILD_SPEC.md requirement.

> **Note for pilot team:** Automated screenshot capture requires a running browser environment. 
> Run `pnpm dev` then capture screenshots manually, or use Playwright with `pnpm exec playwright screenshot`.
